# MR Bubble App (MR Bubble Pro) 🔮

A standalone, next-generation **Medical Representative (MR) Detailing & Territory Management Suite** featuring physics-based interactive doctor bubble canvases, E-detailing slide presentations, Daily Call Reports (DCR), Sample Inventory management, side-by-side photo showcases, and a relaxing stress-relief bubble pop mini-game.

---

## 🌟 Key Features

1. **Side-by-Side Photo Showcase**: Features in-clinic doctor detailing and product formulation visual aids with high-resolution lightbox controls.
2. **Doctor Territory Bubble Canvas**: 2D HTML5 canvas with floating physics bubbles representing target doctors (sizing reflects Rx potential, color indicates specialty).
3. **E-Detailing Slide Presentation**: Interactive scientific slides with weight-based dosage calculators.
4. **Daily Call Report (DCR) & Sample Tracker**: Real-time logging of doctor calls, POB values, sample inventory, and history log.
5. **Mind Refresh Bubble Pop**: Physics-based bubble wrap popping stress reliever with synthesized Web Audio sound effects.

---

## 🚀 Quick Start

### 1. Launch Dev Server
Run the local HTTP server:
```bash
npm start
# or
python3 -m http.server 8095
```

### 2. View in Browser
Open `http://localhost:8095` in your browser.
